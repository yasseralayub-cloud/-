# دليل تشغيل ونشر موقع قائمة الطعام (Menu) مجاناً بالكامل 🚀

تم إعداد هذا المشروع وتجهيز كافة الملفات ليكون جاهزاً للرفع الفوري على **GitHub** وتشغيله على منصات الاستضافة المجانية مثل **Vercel** أو **Netlify** دون دفع أي رسوم وبشكل مجاني 100%.

---

## 🛠️ كيف يعمل الموقع مع قاعدة البيانات؟
الموقع مبرمج بالكامل كـ **Single Page Application (SPA)** باستخدام **React, Vite, Tailwind CSS, and Firebase**.
لا يتطلب هذا الموقع أي خادم (Server) مدفوع؛ حيث يعتمد بالكامل على **Firebase** التابعة لـ Google لإدارة قاعدة البيانات واستضافة الصور في الخطة المجانية (Spark Plan) التي تقدم حدوداً ممتازة كافية جداً للمطاعم والمقاهي مجاناً بالكامل.

---

## ✨ ملفات التهيئة المضافة لتسهيل النشر المجاني:
1. **`vercel.json` (تمت إضافته في الجذر):** لضمان عمل الروابط الداخلية مثل لوحة التحكم `/admin` وصفحة تسجيل الدخول `/login` وتجنب مشكلة الـ (404 Error) عند النشر على منصة **Vercel**.
2. **`public/_redirects` (تمت إضافته):** لضمان توجيه الروابط بشكل ممتاز وبدون أي أخطاء عند اختيار الاستضافة عبر منصة **Netlify**.
3. **`firebase-applet-config.json`:** يحتوي على إعدادات ورموز الاتصال بقاعدة بيانات Firebase المباشرة الخاصة بك لكي يعمل الموقع فوراً وبدون أي تعديل.

---

## 📦 الخطوة 1: تحميل ملفات الموقع كاملة على جهازك لتجهيزها للرفع
لتحميل الكود كاملاً من هنا:
1. اذهب إلى **الإعدادات (Settings)** في القائمة الجانبية لتطبيق AI Studio.
2. اضغط على خيار **تصدير كـ ZIP (Export as ZIP)** لتحميل الكود بالكامل على جهازك.
3. قم بفك الضغط عن الملف في جهازك.

---

## 💻 الخطوة 2: تشغيل الموقع وتجربته محلياً على جهازك (اختياري)
إذا أردت تجربة الموقع وتطويره على جهازك:
1. تأكد من تحميل برنامج [Node.js](https://nodejs.org/).
2. افتح مجلد المشروع في واجهة الأوامر (Terminal) واكتب:
   ```bash
   npm install
   ```
3. لتشغيل الموقع محلياً للتجربة:
   ```bash
   npm run dev
   ```
4. لإنشاء النسخة النهائية الجاهزة للنشر:
   ```bash
   npm run build
   ```

---

## 🐙 الخطوة 3: رفع الكود على حسابك في GitHub
رفع كود الموقع على جيت هوب يجعلك قادراً على ربطه بالاستضافة المجانية بضغطة زر وتحديث الموقع تلقائياً بمجرد تعديل الكود:
1. ادخل إلى موقع [GitHub](https://github.com/) وسجل دخولك (أو أنشئ حساباً جديداً مجاناً).
2. اضغط على زر **New** لإنشاء مستودع جديد (Repository).
3. سمِّ المستودع باسم مناسب (مثال: `my-restaurant-menu`).
4. اختر المستودع ليكون **Public** أو **Private** (حسب رغبتك) ثم اضغط **Create repository**.
5. ارفع الملفات التي قمت بفك الضغط عنها إلى المستودع باستخدام برنامج [Git] أو ببساطة عبر سحب وإفلات الملفات مباشرة (Drag and Drop) إلى صفحة المستودع على جيت هوب.

---

## 🚀 الخطوة 4: النشر المجاني للموقع للعامة (اختر المنصة المناسبة لك)

نوصي بشدة باستخدام **Vercel** أو **Netlify** كونهما أفضل وأسهل من GitHub Pages في التعامل مع النقر المباشر على روابط لوحة التحكم لوجود التهيئة الجاهزة التي قمنا بإنشائها لك.

### الخيار أ: النشر عبر Vercel (موصى به - مجاني 100%)
1. اذهب إلى موقع [Vercel](https://vercel.com/) وسجل دخولك باستخدام حسابك في **GitHub** بضغطة واحدة.
2. اضغط على زر **Add New** ثم اختر **Project**.
3. ستظهر لك قائمة بمستودعات جيت هوب الخاصة بك، ابحث عن مستودع المنيو واضغط **Import**.
4. اضغط على زر **Deploy** مباشرة دون تعديل أي إعدادات.
5. خلال أقل من دقيقة، سيكتمل النشر وسيعطيك الموقع رابطاً مجانياً عاماً ينتهي بـ `.vercel.app` (ويمكنك لاحقاً ربط نطاق "دومين" خاص بك مجاناً).

### الخيار ب: النشر عبر Netlify (مجاني 100%)
1. اذهب إلى موقع [Netlify](https://www.netlify.com/) وسجل دخولك باستخدام حسابك في **GitHub**.
2. اضغط على **Add new site** ثم اختر **Import an existing project**.
3. اختر **GitHub** ثم حدد مستودع الموقع الخاص بك.
4. اضغط على زر **Deploy site** مباشرة.
5. ستحصل فوراً على رابط مجاني ينتهي بـ `.netlify.app` تفتحه من أي مكان في العالم.
